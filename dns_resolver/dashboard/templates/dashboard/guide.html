4 {% trans "Bağla & doğrula" %}

{% trans "Kaydı + sertifikayı ayarladıktan sonra Sunucular'dan ilgili yöntemi aç, sonra domain üzerinden test et. İstemciler standart portları (DoT/DoQ 853, DoH 443) kullanır:" %}

# DoT
kdig +tls @dns.example.com +tls-hostname=dns.example.com example.com

# DoQ
kdig +quic @dns.example.com example.com

# DoH
kdig +https @dns.example.com example.com
